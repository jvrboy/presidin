# Divergence IQ — Build Guide\n\nThis document describes how to build Divergence IQ for desktop (Windows EXE, macOS DMG) and mobile (iOS IPA, Android APK) from the TanStack Start web app.\n\n## Prerequisites\n\n- Node.js 20+ and npm\n- For desktop: `npm install --save-dev electron electron-builder`\n- For mobile: `npm install --save-dev @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios`\n\n## Desktop builds (Electron)\n\nThe Electron shell lives in `electron/`. It wraps the built web app and adds native file access for GGUF model loading.\n\n`bash\n# 1. Build the web app\nnpm run build\n\n# 2. Build the Electron main process\nnpx vite build --config electron.vite.config.ts\n\n# 3. Package for current OS\nnpx electron-builder --config electron-builder.json\n`\n\nOutput lands in `release/`:\n- macOS: `.dmg` and `.zip`\n- Windows: `.exe` (NSIS installer) and portable `.exe`\n- Linux: `.AppImage` and `.deb`\n\n### GGUF model loading on desktop\n\nThe Electron preload exposes `window.nativeAPI` with:\n- `openFile(filters)` — native file picker (bypasses browser sandbox)\n- `readBuffer(path)` — reads the GGUF file as an ArrayBuffer for wllama\n- `stat(path)` — file size/name without loading it\n\nThe `local-ai` route auto-detects `window.nativeAPI` and uses it when available, falling back to the browser `<input type=\"file\">` picker in web mode.\n\n## Mobile builds (Capacitor)\n\n`bash\n# 1. Build the web app\nnpm run build\n\n# 2. Add native platforms (first time only)\nnpx cap add ios\nnpx cap add android\n\n# 3. Sync web assets into native projects\nnpx cap sync\n\n# 4. Open in native IDE and build\nnpx cap open ios      # Xcode → Product → Archive → export IPA\nnpx cap open android  # Android Studio → Build → Generate APK\n`\n\n`capacitor.config.json` is pre-configured with the app ID, HTTPS scheme, and HTTP plugin for CORS-free API calls.\n\n## Offline-first storage\n\nAll data routes use `src/lib/store/offline.ts`, which auto-detects Supabase and falls back to localStorage when unconfigured. This means the app works standalone in Electron/Capacitor without any backend — user data persists locally.\n\n## Environment\n\nSupabase credentials in `.env` are optional. When absent, the app runs in offline mode. For cloud sync, fill in:\n`\nSUPABASE_URL=...\nSUPABASE_ANON_KEY=...\n`\n
